

#### 报告大纲：

〇、投资要点

报告开头给出结论：建议（继续尽调 / 推进 / 放弃）、3–5 条核心论点（每条有数字或来源支撑）、最关键的假设，以及核验中发现的主要事实偏差。

一、关键概念及定义

假设报告的受众是小白，对这个产业和赛道一点也不清楚，介绍core concepts and its definitions，由浅入深，用于扩大搜索空间。

- 由浅入深分层讲解（为什么需要 → 用什么材料/技术 → 产品类型 → 封装/系统形态 → 目标公司所在的具体位置）。
- 文末附术语表：生僻词、缩写、单位换算，各用一句话解释。

二、公司概况：

主体名称、成立时间、注册地、股权结构/实控人、融资历程（轮次/金额/时间/投资方）。

- 关联方与关联董监：股东方在公司的任职、合资公司及其全部股东。
- BP 关键主张核验：工商信息、历次股权变动、融资金额与估值，逐项与工商登记、上市公司股东公告、媒体报道交叉核对，列出核验状态（已核验 / 部分核验 / 矛盾 / 无法核验）。上市公司股东或合资方的公告是首要信息源。
- 股权变动对比：公告值与 BP 值并列，解释每一处差异。

三、业务与产品：

核心产品/服务，产品的技术路线、应用场景、商业模式、客户与合作伙伴（如可公开）、交付与收入逻辑。

- 3.1 产品在下游中的位置：配示意图，标明目标公司的产品位于何处、卖给谁、谁最终买单。
- 3.2 产品线：每条产品线的技术路线、关键参数、应用场景、进度、客户。
- 3.3 商业模式与收入逻辑：卖什么形态（芯片 / 器件 / 模块 / 服务），毛利结构。
- 3.4 核心技术指标表：指标 | 通俗解释 | 方向（越大越好 / 越小越好 / 越接近目标越好） | 行业典型及头部水平（注明测试条件） | 目标公司数值。公司未披露的指标标注为待补数据，并列入尽调问题清单。
- 3.5 技术路线选择：为什么用这条路线而不用其他路线；同一路线为什么选这家而不选竞对。
- 3.6 生产流程与技术壁垒：逐道工序说明做什么、难在哪里、目标公司如何承担（自有 / 外协 / 依托股东）。
- 3.7 产业链：上游材料与设备、中游、下游各环节的代表厂商。

四、市场与竞品：

所在赛道规模与增速（给出数据口径与来源），分成 bottom-up 和 top-down 两种方式、核心竞品对比。

- 市场规模：top-down 与 bottom-up 需统一口径（出货量 / 金额 / 端口），写明公式与每个输入的来源。关键单价缺失时给出情景敏感度，并明确标注为假设。
- 核心竞品：按产品线分别列出全球头部（含海外）、A 股/港股可比公司、创业公司（≥3 家，含最新融资）。每家注明角色（外售 / 自用 / 客户兼潜在自研方），并在同一测试条件下做产品指标对比，而不只列公司名单。
- 竞争格局判断：透过名单看本质，说明竞争的关键已转向哪个维度（如功率档位、良率、可靠性认证、产能）。

五、团队：

核心管理层与关键技术人员履历（可核验来源）。

- 核验方式：全名、前雇主、在职时间，以公开渠道（工商、上市公司公告、论文 / 专利）核对。
- 前雇主竞业限制与 IP 归属；退出经历的真实交易结构。
- 关键人依赖度与全职状态。

六、经营与里程碑：

收入情况、关键商业化开拓进展、项目落地。

- 已发生的里程碑与未来节点分开列出，未来节点注明对收入预测的影响。
- 管理层预测按产品线拆分，检查分项合计与总额是否一致、毛利率假设是否与产品结构相符。

七、估值与交易：

- 本轮条款与估值：投前 / 投后、出让比例、资金用途、跑道测算。
- 历轮估值变化及其支撑。
- 对应管理层预测的 P/S、P/E；可比上市公司与可比融资估值。
- 估值的关键假设与敏感性；条款建议（如分期交割、估值调整）。

八、风险与合规：

政策/技术/供应链/客户集中/财务与现金流/诉讼舆情等。

- 补充：关联交易与公司治理；信息披露一致性（BP 与公开记录的出入）；竞业与知识产权。
- 风险需量化并与预测挂钩（例如：某客户推迟会使当年收入降至多少）。

附录

- 附录 A：管理层访谈问题清单，汇总所有未核验事项与数据缺口。
- 附录 B：数据来源，编号列出（含 URL 与日期），正文以〔S1〕等方式引用。



#### **验收标准：**

- 理清楚其中基本概念，概念之间的区别与联系；
- 讲清楚企业的主要产品和服务是什么，用在下游产品的什么位置（最好配图），客户是谁（谁买单）
- 评判产品的核心技术指标有哪些？为什么用这个技术路线，而不用其他技术路线？同一条路线，为什么用这家的产品，而不用竞对的产品？
- 技术壁垒：产品生产流程是怎样的，上下游有哪些厂商参与，做起来难吗？难在哪里？
- 竞争格局如何？只是回答竞争对手有哪些还不够，还要透过迷雾看本质，进一步从产品层面看各家产品的区别
- 产品有多大市场？不是说市场小而美就不投，这个要结合竞争格局来看，比如启尔机电，浸液系统市场规模 20 亿元一年，但是技术壁垒非常高，全国独家，那么也可以投。
- BP 关键主张已与公开记录交叉核对，矛盾之处在正文和投资要点中明确指出。
- 估值有依据：说明本轮估值相对历轮和可比公司的位置，以及支撑它的关键假设。
- 格式规范：首行缩进，大纲一目了然，图表清晰易读，注明数据来源，生僻的词、概念单独梳理出来解释。
- 数据口径：每个数字注明口径（BP 口径 / 一手公开来源 / 二手转述 / 本报告计算）。缺失数据统一标记为 [DATA NEEDED]，不得估填。
- 版面：每张表格和图不超过一张 A4 Sheet 的高度。竞品对比、技术指标、核验表等容易写长的表，按产品线、年份或维度拆成多张表，每张各带表头和来源。打开报告时页面顶部不应出现 Oversized table 警告（见 `design.md`「Sheet 与分页」）。
- 交付形式（可选）：单文件 HTML，带侧栏目录（含页码）、A4 分页与页眉页码、三种主题和批注功能，便于团队阅读与讨论。
