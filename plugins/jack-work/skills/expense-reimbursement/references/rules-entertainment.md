# 招待客人规则

出处：《报销检查清单-发给财务之前过一遍.md》+ 业务招待备案表样例。

## 审批
- **以后尽量不要招待项目方；招待也要提前向审批负责人申请。**
- 招待须先填**业务招待备案表**（经批准），报销时附备案表 + 用餐支付单/付款记录。

## 备案表字段
- 申请部门、申请日期、接待负责人、参与接待人数、客人单位/人数、接待事由、
  申请金额、申请标准、具体方式（餐饮/礼品/其他）。
- **申请标准**：样例为 **250 元/人**，但这是样例值，**不写死**；按当次审批实际填写。
- 申请日期同样建议早于报销日（与出差时序一致）。

## 金额
- 报销金额合计 = 各餐饮发票**价税合计（小写）之和**。
  - 黄金样例（启浦）：咖啡 125 + 川菜 317 = **442**（报销单 F4 可写 `=125+317`）。
- 大写用 `scripts/rmb_capitalize.py`。

## 字段来源提醒
- A 类：各发票价税合计、金额合计、大写。
- B 类（须问用户）：接待事由、客人单位/人数、申请金额、申请标准、参与接待人数、具体方式。
