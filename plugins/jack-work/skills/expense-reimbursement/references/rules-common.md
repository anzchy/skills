# 通用规则（打印 / 发票 / 附注）

出处：各官方模板「费用报销单」附注栏 + 《报销检查清单-发给财务之前过一遍.md》。

## 打印
1. 费用报销单 / 出差费用报销单 / 出差申请单 / 业务招待备案表 / 参会申请单 /
   组织会议申请单 / 员工培训申请单 / 费用超支申请表 / 付款审批单：
   **A5 纸张、横向打印**（打印区域不含附注栏）。

## 发票
2. 增值税专用发票（纸质）：**发票联与抵扣联分开提供**。
3. 增值税专用发票（电子）：**缩放打印 2 张** —— 1 张用于报销、1 张用于抵扣。

## 各类报销需附材料（费用报销单附注 1–9，本 skill 用到 4/5）
4. 市内交通费报销 → 附**市内交通费清单**，并附**行程单**（如有）。
5. 餐饮招待费报销 → 附**业务招待备案表**，并附**用餐支付单或付款记录**。
6. 出差费用报销 → 附经批准的**出差申请单**、**参会申请单**(出差参会适用)、**出差报告**。
7. 城市间交通费（铁路/飞机）→ 附报销凭证、航空运输电子客票行程单。
8. 住宿费 → 附住宿明细单/清单，能显示**起止时间、单价**。

## 一事一号
- **1 个报销事项 = 1 个序号**，不要把多个事项记在一起。
