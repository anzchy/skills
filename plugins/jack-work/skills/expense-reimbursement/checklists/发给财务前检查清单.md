# 发给财务前检查清单（三类）

产出报销单后、发给财务前，按类别逐项过一遍。✅ 全勾才提交。

## 通用（三类都查）
- [ ] 费用报销单已选 **A5、横向** 打印（打印区不含附注）。
- [ ] 金额合计、**大写**正确（大写用 `rmb_capitalize.py`，不手算）。
- [ ] 1 个报销事项 1 个序号，未混记。
- [ ] 电子专票缩放打印 2 张（报销 + 抵扣）；纸质专票发票联与抵扣联分开。

## ① 市内交通
- [ ] 已附**交通费报销清单** +（如有）**行程单**。
- [ ] **发票张数**：同一发票多行程只记 1 张；张数合计 = 平台数（每平台 1 张电子发票）。
- [ ] 每条行程都有**事由**；行程地点写法已规范化。
- [ ] 解析金额与行程单自报「合计」已交叉核对；被剔除的行程（个人/不报）已确认。
- [ ] 报销测算（如填）：仅**滴滴快车**计入抵扣；曹操/T3/出租车未计入。

## ② 出差
- [ ] **出差申请单**经批准，且日期早于报销日 **≥2 天**。
- [ ] **出差报告本人已签字**。
- [ ] 城市间交通费 = 票价 × 人数（已核对高铁/机票行程单）。
- [ ] 住宿费 = 住宿发票价税合计，发票显示**起止时间、单价**。
- [ ] **餐补**按 `meal_subsidy.py`（城市档 × 人数 × 天数，半天按全天）核对。
- [ ] 市内接驳票据已附；出差参会已另附**参会申请单**。

## ③ 招待
- [ ] 招待**已提前向审批负责人申请**；**业务招待备案表**经批准。
- [ ] 已附**餐饮发票** + **支付截图/付款记录**。
- [ ] 金额合计 = 各发票价税合计之和；申请金额/标准按实际审批填（非样例 250）。
