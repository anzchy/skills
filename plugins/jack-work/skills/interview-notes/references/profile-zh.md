# profile-zh — 中文访谈纪要约定

本文件是 `interview-notes` 的**中文默认约定**。SKILL.md 的规则是语言无关的；所有
中文特有的字符串都在这里，而不是内嵌在规则里。

**这是一次逐字搬迁，不是重写。** 每一条都标了它在源命令
`analyst-dd/commands/interview-notes-enricher.md` 里的行号，字符串与源文件逐字节一致。
若要改写其中任何一条，先改 SKILL.md 的规则，别改这里的字面量 —— 改了就没法再对账。

> **memo 永远优先于本文件。** 本文件只为 memo **没有表现出来**的观察量提供默认值。
> 两者冲突时以 memo 为准，并把偏差写进 Phase 6 报告。（源 `:85`）

---

## 1. Q/A 标记

全角冒号（`：` 而非 `:`），Q 行加粗、A 行不加粗（源 `:73-79`）：

```markdown
**Q：<问题>？**

A：<回答原话或最小改写>
```

## 2. 小节标题

`### N.M 主题`，例如 `### 1.2-1.3 成本结构与供应链`（源 `:80`）。

新 Q&A 放进**最相关的既有小节**；只有明显有必要时才新建小节。

## 3. 访谈小节标题与边界

- 小节标题形状：`## 访谈 N | 姓名 · 角色`（源 `:48`、`:65`）
- Grep 定位用的两个正则（源 `:95`，"be liberal — heading conventions vary"）：
  - `## 访谈 \\d+ \\| <name>`
  - `## .*<name>.*\\|`
- 小节读取边界：从它的 `## 访谈 N | <name>` 读 `to the next `## 访谈` or `---` separator`（源 `:102`）

## 4. 模糊限定语（hedge）

当转录稿里的说法更像访谈者的解读而不是受访者的明确陈述时，用（源 `:81`、`:145`）：

- `访谈口径是…`
- `访谈口径约…`

## 5. 数字

保留转录稿原样，不四舍五入、不换算（源 `:82`）：

> Numbers: keep transcript figures (亿元 / 万美金 / %) verbatim; do not round or convert.

## 6. 禁用形式

不用 emoji；不写 `"补充" or "新增"` 这类小标题；新条目必须与既有条目**看不出区别**（源 `:83`）。

## 7. 问句识别

访谈者一侧的发言，以 `？`/`?` 结尾，或以下列词开头且在索取信息（源 `:108`）：

```
那 / 你们 / 比如说 / 现在 / 能不能 / 是不是 / 有没有 / 怎么 / 如何
```

**不是问句**的插话（源 `:155`）：`"嗯", "对对对", "好的"`。

## 8. 可清理的语气词

轻度清理以下填充词、重复语、明显的语音转写残迹是允许的；**不得**改写成概括（源 `:126`）：

```
那个 / 就是 / 对对对
```

## 9. 文件名 glob

- memo 候选（源 `:32`）：`*纪要*final*.md *纪要-final.md`
- 转录稿候选（源 `:39`、`:41`）：
  - `20[0-9][0-9][01][0-9][0-3][0-9]-*访谈.md`
  - `20[0-9][0-9][01][0-9][0-3][0-9]-*交流.md`
  - 兜底示例：`./*访谈*.md`、`./*交流*.md`

## 10. 姓名匹配

按转录稿文件名匹配受访者时，除中文姓名外，也试 **pinyin** 与角色关键词（源 `:94`）。
