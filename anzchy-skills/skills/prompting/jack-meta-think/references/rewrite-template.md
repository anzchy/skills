# 结构化提问模板与范例

模板由原文的 CD 机正例泛化而来。**不是每一栏都必须填** —— 不适用就整栏删掉，缺失就保留 `[待你补充]`，不要编。

---

## 模板

```
[对象标识]   具体是什么东西的哪个版本。型号 / 品类 / 产地，或 框架 + 大版本 + 运行环境。
[环境条件]   在什么条件下使用、运行。
[时间线]     最后一次正常是什么时候 → 中间发生了什么 → 现在从什么时候开始异常。
[具体现象]   用动词和名词描述可观察的行为与结果。禁止形容词单独成句。
[已排除]     我试了 X，结果 Y，因此可以排除 Z。
[已确认事实] （仅当用户明确确认过某前提时才有这一栏）据我确认，……
[开放问句]   请分析原因，并提出建议。／ 为什么会变成这样？／ 如何做到 X？
```

原文正例，逐栏对照：

> 我的**索尼 D-NE800 便携式 CD 播放器**〔对象标识〕现在无法通电。这是一台**日本原产** CD 机，我**使用两节口香糖电池供电**〔环境条件〕。**昨天工作一切正常，但是今天无法开机**〔时间线〕，**屏幕不亮，按键无任何反应，一直处于不通电状态**〔具体现象〕。**我把电池换到其它 CD 机上，工作正常**〔已排除〕。**请帮我分析故障原因，然后提出维修建议**〔开放问句〕。

## 范例 A · 技术域（预设结论被拆掉）

**原话**

> 帮我写个 prompt，让 Claude 修掉 React hydration 导致的白屏。

**诊断**

- C1 FAIL：「hydration 导致的」是未经验证的预设。照此提问，AI 只会顺着 hydration 这条线给出一套头头是道的论证——和「分析这张图里的倭风」是同一个机制。
- C5 FAIL：没有时间线。C7 FAIL：没有交代自查动作。

**追问**（C9 动作）：你是想**验证白屏是不是 hydration 引起的**，还是想**弄清白屏到底为什么发生**？

用户选后者，于是改写为：

```
我的 Next.js 14（App Router，React 18，Node 20，本地 dev 环境）项目首屏白屏。

时间线：上周五部署的版本正常；周一我把用户头像组件从 server component 改成了 client component，
之后本地 dev 首屏开始白屏。

具体现象：浏览器标签正常加载，页面 body 为空，控制台报 "Text content did not match"
警告一条，无 error。刷新后偶尔能正常渲染，大约三次里有一次。

已排除：清了 .next 缓存和 node_modules 重装，现象不变；生产构建 next build && next start 下
不复现，只在 dev 复现。

请分析首屏白屏的可能原因，按可能性排序，并说明各自的验证方法。
```

关键差异：原话锁定了答案，改写后交出了「刷新三次有一次正常」和「仅 dev 复现」这两条——它们恰恰指向 hydration 之外的方向。

## 范例 B · 生活域（评价词被还原为事例）

**原话**

> 我室友总是在针对我，你说他是不是品行有问题？

**诊断**

- C1 FAIL：「针对」和「品行有问题」都是定性。这个问法把真与假、以及「自身有误判」的可能性一起藏掉了。
- C2 FAIL：全是评价，没有事例。

**追问**（C9 动作）：你这个问题预设了「他在针对你」。你是想**验证他是不是真的在针对你**，还是想**弄清事情为什么变成现在这样**？

用户选后者，于是改写为：

```
我和室友同住一年半。前一年相处正常，会一起做饭。

三个月前我换了工作，作息从 9-6 变成经常加班到十一点回家。此后发生过三件事：
1. 我半夜回家做饭，他第二天在群里说「厨房太吵」；
2. 他把我放在客厅的健身器材挪进了我房间，没有事先说；
3. 上周我提议轮流打扫，他回「你在家的时间本来就少」。

我这边的处置：第 1 件之后我改成回家不做饭；第 2 件我没提；第 3 件我当时没接话。
我没有直接问过他是否对我的作息有意见。

请分析事情为什么会发展成现在这样，包括我自己的行为可能起了什么作用。
```

关键差异：把「针对」拆回三个可观察事件，并交代了自己的处置——第三方（人或 AI）这才有可能给出中立判断，而不是被迫顺着「他有问题」往下讲。

## 改写时的自查

1. 通篇是否还剩下没有事例支撑的定性词？
2. 结尾的问句，去掉前面所有叙述之后，是否仍然只有一个答案是「合理」的？如果是，它还是诱导性提问。
3. 用户没回答的每一个空，是否都留了 `[待你补充]` 而不是被我猜测填上？
