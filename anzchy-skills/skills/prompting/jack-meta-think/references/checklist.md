# 提问判据清单 C1–C10

来源：`docs/references/和菜头关于如何提问.md`。每条只提炼文中真实存在的内容，不掺入通用 prompt engineering 常识。

**C1–C7 可从文本判定**，用于 Phase 1 扫描。
**C8 为弱判据**，只作提示。
**C9、C10 不可从文本判定**，只能作为 Phase 2 的追问动作 —— 永远不要给它们打 PASS/FAIL。

---

## C1 · 无预设结论（开放性提问）

- **判定信号**：疑问句的宾语或前提里嵌入了未经证实的定性判断。典型句式：「请分析 X 里的 Y」（Y 的存在本身未证实）、「他是不是 Y」（Y 为定性）、「为什么 Y」而 Y 待验证。
- **反例特征**：同一张功夫大师打拳的照片，问「分析一下这张图里的倭风」得到日本风格的头头是道论证，问「分析一下这张图里的泰国风」得到东南亚美学的头头是道论证。「我同事总是在针对我，你说他是不是品行有问题」——「针对」一词本身隐藏了针对的真与假，隐藏了自身有问题、自身有误判等可能性。
- **改写动作**：删除定性词，还原为中立事实叙述；把「是不是 Y」改为原文给出的正面模板「为什么事情会变成这样？」
- **原文锚点**：「避免加入任何个人判断，然后给出一个开放性的提问」；「答案已经预设在问题里了……是用问题的形式包装起来的观点」；魔镜问的是「谁是世界上最美丽的女人」，不是「为什么我是世界上最美的女人」。

## C2 · 事实与判断分离（中立事例叙述）

- **判定信号**：叙述部分是否只含可观察事实（谁、何时、做了什么、结果如何），还是混入了评价性形容词。
- **反例特征**：「我的队友根本不顾家，工资也不交」——「不顾家」是评价，不是事例；事例已经按结论筛选过。
- **改写动作**：把每个评价词替换成该评价所依据的具体事件，判断留给回答方。
- **原文锚点**：「事实准确、条理清晰、逻辑链条完整」；「用尽量中立的事例，讲述他们之间的一次冲突的前因后果」。

## C3 · What / Why / How 优先于观点、感受型提问

- **判定信号**：核心疑问结构 ∈ {是什么 / 为什么 / 如何做到} → PASS；∈ {怎么看 / 什么感受 / 怎么样 / 好不好} → FAIL。
- **反例特征**：「你对鱼香茄子这道菜怎么看？」「吃一份鱼香茄子是什么感受？」——原文评价为「原型就是寒暄闲聊，但是包装成一幅正在思考的样子」。
- **改写动作**：拆成三连问，模板即原文正例：「鱼香茄子是什么？为什么会有鱼香？怎么做一份鱼香茄子？」
- **注意**：祈使句（「帮我修 X」）不算 C3 失败，不要把 W/W/H 形状硬套到指令上。
- **`[不可判定]` 的半条**：原文「一路追问下去……直到逼近自己知识的盲区」是多轮对话行为，单条提问无法判定；可判定的只有首问是否属于 W/W/H 型。

## C4 · 基础标识信息完备（压缩搜索空间之一）

- **判定信号**：涉及具体对象时，是否给出型号 / 品类 / 版本级别的标识。
- **反例特征**：「我的 CD 机坏了，你告诉我怎么修」——原文评价「信息量几乎为零……这叫做『索取情绪价值』」。
- **正例**：「索尼 D-NE800」（具体型号）+「便携式 CD 播放器」（品类双保险，因为字母数字型号可能雷同）+「日本原产」（同款有马来西亚版和日本本土版，产地进一步缩小范围）。
- **改写动作**：追问「这是什么东西的哪个具体版本」。软件域的等价物是 框架 + 大版本号 + 运行环境。

## C5 · 时序化的变化叙述

- **判定信号**：是否存在「之前正常 → 变化点 → 之后异常」的时间线。
- **反例特征**：只给当前状态快照，没有变化过程。
- **改写动作**：按时序重排叙述，明确「最后一次正常是什么时候」「中间发生了什么」。
- **原文锚点**：「按照时序讲述前后变化，因为出现故障其实是一种变化，而变化和时间密切关联。三个月没开机，和隔天开机，这完全是两个概念。」

## C6 · 抽象词展开为具体动词与名词

- **判定信号**：症状用可观察的行为动词 + 名词描述，还是停留在形容词。
- **反例特征**：「坏了」「很卡」「不好看」作为唯一描述。
- **正例**：「无法开机，屏幕不亮，按键无任何反应，一直处于不通电状态」。
- **改写动作**：对每个抽象词追问「具体表现是什么行为、什么结果」。
- **原文锚点**：「展开『坏了』两个字，『坏』是个抽象概念，形容词……在任何时候想要描述清楚什么，都必须使用大量动词和名词。全用抽象概念那是为了抒情。」

## C7 · 主动排除已验证因素（压缩搜索空间之二）

- **判定信号**：是否含「我尝试了 X，结果 Y，故可排除 Z」结构。
- **反例特征**：完全不交代自查动作，让回答方从全空间猜起。
- **正例**：「我把电池换到其它 CD 机上，工作正常」——主动帮 AI 排除「电池无电」这一种可能。
- **改写动作**：追问「你自己试过什么？结果如何？」写成排除清单。
- **与「约束」的区别**：C7 压缩的是**输入的假设空间**（哪些原因已排除），不是约束**执行者的行为**（不许改哪些文件）。两者不同层，不要混为一谈。
- **原文锚点**：找工程师「我自己的排故尝试，尝试的结果分别是什么，可以排除掉的因素有哪些」；找医生「对于目前的症状我自己做了什么处置，效果如何」。

## C8 · 附加证据材料 `[弱判据]`

- 原文仅一句带过：「为了防止我忽略了某些细节，我还拍了机器的几张照片给 AI」。
- 是否需要附材料完全依赖任务性质，无通用阈值。**只作提示性检查项，不作二元判据**：有截图 / 日志 / 报错原文可附时提醒一句即可。

## C9 · 意图自检：期待赢，还是期待真实 `[不可判定]`

- **为什么不可判定**：意图在提问者心里，文本层没有 ground truth。同一句「他是不是在针对我」，可能出自真诚困惑，也可能出自寻求站队。机器只能检测其文本表征（即 C1 / C2），无法判定意图本身。
- **可执行的转化 —— 这是 Phase 2 的第一个追问**：向用户复述「你这个问题预设了 X。你是想验证 X 成不成立，还是想弄清事情为什么变成这样？」让用户自答。
- **原文锚点**：「在说话前自检一遍：我到底要说什么？我到底要问什么？我是在期待赢，期待满足，还是期待真实，期待启发？」

## C10 · 目的层反思：反应 vs 思考 `[部分不可判定]`

- **为什么不可判定**：「这个人是否思考过」无法从单条提问判定。
- **可判定的弱形式**：提问是否只有操作层问题（怎么做），完全不交代目标（为了什么）。
- **可执行的转化 —— Phase 2 的第二个追问，只在方法被锁死时才问**：「你要 X 是为了达成什么？如果目标是 Y，X 是唯一路径吗？」
- **原文锚点**：减肥案例——说到减肥立即反应要节食，节食成功再反弹，反弹再节食；「肌体的状态和膳食平衡、营养均衡、睡眠质量、日常运动以及压力大小有关，改变单一因素不会改变整体状态」。饺子案例——「我今天为什么要吃饺子」把人从具体的包饺子里解脱出来。
- **不要反射性地问**：每次都问会读作拖延。只在方法固定、目标未审视时触发。

## C11 · 学点哲学 `[不可判定]`

原文第四部分末尾的长期修养建议与书单（《哲学的故事》《苏菲的故事》），与任何单次提问的可检查属性无关，**不纳入清单**。
